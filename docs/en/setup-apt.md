# Set up the FreeSynergy APT source (Debian, Ubuntu, node1)

As root. The key is fetched, **its fingerprints are checked by you**, and only then trusted for this source only (`Signed-By`, never `apt-key`/`trusted.gpg.d`).

```sh
install -d -m 0755 /etc/apt/keyrings
tmp=$(mktemp -d)
curl -fsSL https://freesynergy-net.github.io/Repository/apt/freesynergy-archive-keyring.asc -o "$tmp/key.asc"
gpg --show-keys --with-fingerprint --with-subkey-fingerprints "$tmp/key.asc"
```

The primary key fingerprint must be exactly `16A4 A3EE 563A EF51 FCF0 C55D ED7B 57C4 A190 4342`, the signing subkey `372A 583D 05BF 8362 604C F25D E26A 2347 F2B1 C097`
(compare with the project website). If not: stop.

```sh
gpg --dearmor < "$tmp/key.asc" > /etc/apt/keyrings/freesynergy-archive-keyring.pgp
curl -fsSL https://freesynergy-net.github.io/Repository/apt/freesynergy.sources -o /etc/apt/sources.list.d/freesynergy.sources
rm -rf "$tmp"
apt update
apt install zentinel        # or kanidmd
```

`freesynergy.sources`:

```
Types: deb
URIs: https://freesynergy-net.github.io/Repository/apt/
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/freesynergy-archive-keyring.pgp
```

**Suites:** `stable` holds full releases, `testing` pre-releases. As long as a program only has pre-releases (for example Zentinel before its first
full release), `stable` does not exist and the ready-made file (generated by `make-site.sh`) already says `Suites: testing`; change that word to
`stable` once you want only full releases. `apt update` must not print "not signed" or "NO_PUBKEY"; if it does, do not install anything.
Check the tree without apt: `scripts/verify-apt.sh --fingerprint 16A4A3EE563AEF51FCF0C55DED7B57C4A1904342 <tree> <suite> /etc/apt/keyrings/freesynergy-archive-keyring.pgp`.
